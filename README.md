# Wymark

Issues, releases and release notes for [Wymark](https://wymark.app), a markdown editor with track changes and comments. The editor's source is not in this repository.

- Download the latest build from [wymark.app](https://wymark.app) or from [Releases](https://github.com/wymarkapp/wymark/releases). An installed copy updates itself.
- Found a bug, or want something changed? [Open an issue](https://github.com/wymarkapp/wymark/issues/new/choose).
- The notes for every version are under [releases/](releases).
- The [documentation](https://wymark.app/docs) lives on the site.

Wymark is in beta, and macOS only for now.
