The Formatted view now draws the HTML that GitHub draws in a README: keys,
subscript and superscript, highlights, figures, aligned blocks and details.
HTML it does not draw is shown as source in a monospaced face, and a block of
it folds. The drawing editor follows excalidraw.com. A document in a
cloud-storage folder can hold images and drawings. An open app checks for an
update every six hours.

## Highlights

- A matched pair of `<kbd>`, `<sub>`, `<sup>`, `<mark>`, `<ins>` or
  `<small>` is drawn as the element it names. The two tags show when the
  caret arrives, as bold and italic delimiters do.
- A `<figure>` of pictures with a plain-text caption is drawn as its
  pictures and its caption.
- `<div align>` and `<p align>` align what is between their tags,
  `<details>` is a summary row with its content under it (always open), and
  a `<picture>` whose sources are chosen by colour scheme follows the app's
  theme.
- HTML that is not drawn is shown as its source in a monospaced face. A
  block of it sits on a panel with an `HTML` label; clicking the label
  folds the block to its first line. Nothing is written to the file.
- None of this changes the file: the tags are stored, counted and saved
  exactly as before.
- The drawing editor is the build excalidraw.com runs, not the older
  stable release, so its tools match the hosted app.
- Pasting an image or inserting a drawing works in a document under
  `~/Library/CloudStorage`, which includes Desktop and Documents when
  OneDrive folder backup is on. It was refused before.
- An open app checks for an update every six hours, where it checked once
  a day. The check at launch is unchanged.
- Fixed: an arrow key onto a hidden tag or comment left the caret
  apparently still, and the next letter replaced the tag or the comment.
- Fixed: switching back to the Formatted view could land at the top of
  the document.
- Fixed: with the View zoom above 100%, a split pane could not be dragged
  down to its minimum width.
- Fixed: Forget on the missing-file prompt left the document's tab
  standing, and closing that tab crashed the view.
- Fixed: the AI sidecar's HTML comment could raise a conflict card when
  two Wymark apps had the same file open.
