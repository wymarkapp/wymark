The Files search can now stay inside one folder of the open folder. A wide
table no longer scrolls the whole document sideways when you hover it, and a
file made from the Files panel opens with changes hidden.

## Highlights

- Search inside one folder. Pick Find in Folder... on a folder's menu, or
  use the folder button beside the search options and type a path (Tab
  completes it, and lists the subfolders when more than one fits). Name and
  text search both stay inside the folder.
- Fixed: hovering a wide table no longer adds a horizontal scrollbar to the
  whole document.
- Fixed: a file made with New File in the Files panel opens with changes
  hidden, instead of showing all its text as one change.
- Security update to the app's built-in web server (Bandit 1.14.1).
