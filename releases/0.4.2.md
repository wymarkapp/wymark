A document with comments above a changed code block opens again, and a file
that starts with a byte order mark no longer opens broken in the formatted
view. Settings > About can allow the Web Inspector, and several fixes for
Windows.

## Highlights

- New: Settings > About has "Allow Web Inspector", off by default. When it is
  on, the window appears in Safari's Develop menu.
- New: on Windows, F11 toggles full screen.
- Fixed: a document with comment threads above a code block whose code changed
  could not be opened.
- Fixed: when the formatted view had to rebuild itself, what you had typed
  could be dropped. The log now also names why the rebuild happened.
- Fixed: a file that starts with a byte order mark opened with its formatting
  shifted one character, and the next edit wrote that to disk. Files saved by
  an older Wymark no longer show as changed while closed.
- Fixed: on Windows, a window minimized or maximized at quit comes back where
  it was, not off-screen or as a screen-sized window.
- Fixed: on Windows, comments and Word export carry your full name, not your
  login, a failed delete names the Recycle Bin, and the tour knows when
  Wymark already opens .md files.
- Fixed: shortcuts named in tooltips and messages show Windows keys on Windows.
- Security: an update to the cookie library under the app shell.
