Following a link to another document now opens it beside the one you are
reading, and a footnote's hover card takes you to the note. Changing where a
link or a picture points shows as one "Link changed" or "Image changed" card
on it. Two copies of Wymark editing the same document no longer duplicate
its content. The welcome document links the docs page for each feature, so
this update replaces your copy of it again.

## Highlights

- `⌘`-click on a link to another document opens it in a second pane beside
  the one you are reading, making that pane if there is none.
- The footnote hover card can be reached with the pointer, and its arrow
  jumps to the note. `⌘`-click or `⌥`-click on a reference jumps there too.
- A link pointed somewhere else, with its text unchanged, shows as one "Link
  changed" card beside it, with the old target struck. A picture pointed at
  another file shows as "Image changed" on the picture.
- An added code block is tinted as new in the Formatted view, and walking
  onto it no longer makes it blink.
- Fixed: the same document open in two copies of Wymark at once could
  multiply a list item and keep adding empty ones until one copy was quit.
- The welcome document links the docs page for each feature it describes.
  The update replaces your copy of it, along with anything you wrote in it.
