Find in the formatted editor now matches the text you see, and Replace
reaches links, code fences and the front matter without breaking them. The
review gets cards for more structure changes, every window you had open comes
back on launch, and a round of version-history and editing fixes.

## Highlights

- Find in the formatted editor matches the text as you see it, not the
  markdown behind it. It covers links and code fences, Replace keeps a
  link's address, Replace reaches the front matter, and the panel says what
  it will skip.
- Turning a quote into an alert, or changing an alert, gets its own card. A
  list moved into a quote pairs item by item, and a paragraph made a heading
  (or the reverse) gets a "Formatted" card.
- Selected list items can be quoted. Insert > Alert wraps a selection, turns
  the quote at the caret into an alert, or changes an alert's kind.
- Every launch restores every window that was open.
- Help > Third-Party Licences lists the software inside the app, with its
  versions.
- Fixed: a comment reply in a thread at the start of a list item could be
  saved as escaped text after an edit in the formatted editor.
- Fixed: undo across several lines leaves the caret at the start of the
  change; Escape closes one open dropdown at a time; copying from inside a
  bullet or a table cell pastes the way Word does.
- Fixed: in version history, a restore no longer leaves the old changes on
  screen, and a version that removed text shows the removal.
- Security updates to third-party packages, among them a fix for pasting
  crafted HTML into the formatted editor.
