Every right-click menu in Wymark is now a native menu, and the editor, tabs,
the file tree and Recents all have one. Changes are reviewed one paragraph or
one sentence at a time, and a single Export dialog asks for the format and
remembers your choices. Copying inside Wymark keeps comments and the exact
Markdown; pasting elsewhere brings formatted text. A file that is moved,
renamed or deleted while it is open is followed or kept safe, and Save As puts
a document somewhere new with its history. Typing is no longer lost when
another app writes to the file at the same moment.

## Highlights

- Right-click menus everywhere, using your system's own menus: in the editor
  (with formatting, comments and Paste as Incoming Change), on tabs, in the
  file tree, in Recents and in search results.
- Review changes by paragraph or by sentence. Each change now covers one
  Markdown block, so a long edit no longer arrives as one large change.
- Paste as Incoming Change, from the Edit menu or the editor's right-click
  menu, marks pasted text for review instead of counting it as your own
  writing.
- One Export dialog for every format, with its options, remembered between
  exports.
- Copy and paste inside Wymark keep comments and the exact Markdown. Pasting
  into other apps brings formatted text, and Copy As offers Markdown, Markdown
  with comments, formatted text and HTML.
- Select several files in the tree or in Recents, drag them to move them, and
  undo the move in one step. New Folder names itself in the tree, like New
  File.
- A file that is moved or renamed outside Wymark while it is open is followed.
  One that is deleted keeps its text in the tab, marked with a dot, until you
  save it again or choose Save As.
- Typing is no longer lost when another app writes to the file while you type;
  both sets of changes are kept.
- Selecting text shows a small round comment button just under the selection,
  in place of the floating formatting toolbar. Formatting is in the toolbar,
  on the keyboard and in the right-click menu.
- A comment can now sit inside another comment. A selection that crosses an
  existing comment's edge is refused with an explanation, where it used to
  move the existing comment's anchor.
- A picture tab zooms: pinch, or scroll with a modifier key held, use the
  header's controls, or double-click to switch between fit and 100%.
- Recents keeps its order steady and remembers more documents, and a folder
  you have open is always listed in the file tree.
- Fixes for the caret jumping when text above it changed, comments beside
  pictures, split-pane widths, and undo after accepting a change.
