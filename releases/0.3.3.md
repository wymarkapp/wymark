Show changes in the raw editor reads better on hard-wrapped paragraphs: soft
breaks are joined, and the highlight covers just the words that changed. The
Files panel can open forks of other branches, and `wymark open` can land on a
line, heading, change or comment.

## Highlights

- Improved: Show changes in the raw editor joins a paragraph's soft breaks, so a
  hard-wrapped paragraph reads as one block, and the change highlight tints the
  changed text instead of whole lines.
- Improved: change cards no longer show wrapping differences or code backticks
  as edits.
- Improved: the Files panel's pick reaches the documents, and forks of other
  branches can be picked.
- Improved: `wymark open` can land on a line, a heading, a change or a comment.
- Fixed: if the formatted editor fails to apply an outside change, it rebuilds
  itself instead of showing stale text.
- Fixed: a rejected change that cut bytes it only claimed now records its own
  deletion.
- Changed: raw-pane inline code is no longer teal, and the dark HTML colour no
  longer matches the deletion orange.
