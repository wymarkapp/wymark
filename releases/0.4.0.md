Comments show links and pictures, code blocks show their changes in the
formatted editor, and undo takes back larger steps with the caret landing at
the change. Settings are split into four sections, and Cmd+0 resets the zoom.

## Highlights

- New: a resting comment shows a subset of markdown. Web links are live, and
  pictures show as framed thumbnails.
- New: a picture pasted or dropped into a comment box is saved and referenced
  from the comment.
- New: code blocks in the formatted editor show their line changes, as the raw
  editor does, and show their language in the corner. A code block reviews as
  one change in both editors.
- Improved: a typing step for undo ends after a one-second pause, and undo
  lands the caret at the undone change in both editors, scrolled into view.
- Improved: Settings > Appearance is split into Appearance, Editor, Spelling &
  suggestions, and Markdown.
- Improved: the editor scrolls past the end of a document by half a screen.
- Improved: change cards and the change highlighting agree, and a new section
  next to an old block reads as a deletion and new blocks, not one replacement.
- Changed: Cmd+0 resets the zoom, and Paragraph moves to Cmd+Opt+0.
- Changed: drawings use the newest Excalidraw tools, the same as excalidraw.com.
- Changed: a calmer light theme colour.
- Fixed: Cmd+Z inside a code block could empty the document.
- Fixed: Return at the end of a list step with code under it starts the next
  step after the code.
- Fixed: long Mermaid labels wrap at every zoom level.
- Fixed: Search Files works with no folder open.
