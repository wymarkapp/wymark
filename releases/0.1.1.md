Wymark is a markdown editor with the comments and track changes you know from
Word and Google Docs, kept in plain markdown files on your disk. This is the
first public beta build. It reviews any change to a document you own -- a git
commit, a version you saved, a draft you handed to a tool -- as changes you
read, accept, reject and comment on, and from this version on it updates
itself when a newer one is published.

## Highlights

- Word-style track changes over plain markdown, whatever made the change.
- Comments that live in the file, as markdown comments any tool can read.
- A WYSIWYG editor and a raw markdown view of the same file, side by side if
  you like.
- Version history per document, and export to Word with tracked changes and
  comments intact.
- The app checks for a newer version once a day and offers to update itself;
  turn it off in Settings if you prefer.
- Testers on the earlier Markwell builds: this is a new bundle, so install it
  fresh rather than expecting an update.
