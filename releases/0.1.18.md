A list item that starts with a heading, a quote, a code block or a table is
no longer copied into the file on every edit in the Formatted view. Delete
and Backspace now agree at every block boundary, and the review names more
changes for what they are: a join, an unfenced code block, a removed
picture or divider, a picture's new alt text. Moved text keeps its colours,
and a tab dragged to the right of a lone pane opens a second one.

## Highlights

- Fixed: a list item starting with a heading (`3. ### Title`), a quote, a
  code block or a table was copied into the file again on every edit in
  the Formatted view, pulling the next block into the list. The Formatted
  view looked clean throughout. Such an item is now written on its marker
  line, as it was typed, and an edit near it is written once.
- Fixed: Backspace right after typing `[^label]:` or `[label]:` put the
  caret in the next block, so the next Backspace joined that block onto the
  label.
- Delete at the end of a block and Backspace at the start of the next one
  now do the same thing. A rule, a picture or an HTML block is selected by
  the first press and removed by the second. Delete at the end of a bullet
  joins the next bullet's text onto the line, and at the start of a list
  item it deletes the character ahead.
- The review names more changes: a join beside another pending change stays
  "Merged", every one-press bullet join is "Merged", a code block whose fence
  was removed is one "Unfenced" card, a removed picture or divider is a
  note, a picture's changed alt text has its own card, and a removed
  footnote reads "Footnote removed".
- Moved text keeps the colours it had, whether moved with Opt+Arrow or cut
  and pasted back.
- A text that leaves and comes back (`git stash` and `git stash pop`, as
  `git town sync` does) keeps its colours instead of turning all incoming.
- A tab dragged to the right third of the only pane opens a second pane
  beside it.
- The default text column is wider (46rem, about 92 characters).
- A markdown picture is sized from its width, like an `<img>` tag, so a
  wide picture is no longer cropped at the sides.
- A wheel over the margin beside a zoomed text scrolls the document.
- Fixed: a page that sat frozen while the Mac slept could reload itself and
  offer a crash report on wake. Nothing had crashed.
- Fixed: the AI sidecar file could be unparseable when the document held a
  heading joined onto a paragraph.
- Fixed: making a word bold right after resolving a comment could scroll the
  document, so the line you were on slid up under the toolbar.
