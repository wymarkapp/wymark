Undo with nothing in the editors focused no longer empties the file, and Edit >
Undo and Redo in the menu now work. Wymark also never writes an empty comment,
and a double-click past the end of a line puts the caret there.

## Highlights

- Fixed: pressing Undo after clicking outside the editors could empty the file
  on disk. Undo now goes to the document's own history wherever focus is.
- Fixed: Edit > Undo and Edit > Redo in the menu did nothing. They now undo
  and redo in whatever has focus, as the keyboard does.
- Fixed: creating a comment on a selection with nothing to wrap wrote an empty
  comment into the file. Wymark now refuses it and says so.
- Fixed: a double-click past the end of a line selected the line break, so the
  next key joined two blocks. It now places the caret at the end of the line.
