You can now drag a file from Finder into Wymark: drop it on the editor to open
it, or onto the Files panel to copy it into the folder you drop it on. A
folder dropped on the Files panel opens it, or is copied in when a folder is
already open, with an Undo. Comparing a document against a git version no
longer locks the document up, and files that are not UTF-8 are refused with a
clear message instead of crashing the window.

## Highlights

- Drop a Markdown file anywhere in the window to open it in a normal tab, in
  the pane under the pointer. The file stays where it is.
- Drop files onto the Files panel to copy them into the folder under the
  pointer, or into the open folder's root. A copy never overwrites; it gets a
  new name if one is taken, and the copy is revealed in the tree.
- Drop a folder onto an empty Files panel to open it, or onto an open folder
  to copy it in. Undo (Cmd-Z or the toast) moves the copy to the Trash.
- Files Wymark cannot open, such as Word documents, are refused by name.
- Fixed: comparing against a git version could crash the view over and over,
  so the document could not be opened again (0.1.9 and 0.1.10).
- Fixed: whitespace changed inside a code block, such as re-indented YAML,
  showed no change and could not be rejected.
- Files that are not UTF-8 are refused with a message saying how to fix them.
  A file rewritten in another encoding while open stops being saved, so the
  other app's bytes are kept, and resumes when it is UTF-8 again.
