Replaces 0.1.1 to 0.1.4, which have been withdrawn: their bundles carried a
few files from the build machine that were never part of Wymark. Nothing about
the app changes in this version, and if 0.1.4 offered it to you, the update
path has now carried a release end to end twice.

## Highlights

- The bundle contains only Wymark. The earlier beta builds are withdrawn.
- No other user-visible changes since 0.1.3.
