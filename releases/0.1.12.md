Reviewing changes in the Formatted view is calmer. Removed text is shown the
same way whoever removed it, change cards share one amber with the pin and
line that point at them, and the margin bar now marks only the changes you
cannot see in the text, such as a deletion or an edit inside a code block.
Switching from Formatted to Source with changes shown no longer makes the
page jump.

## Highlights

- Removed text no longer takes the green or blue of whoever made the change.
  In a change card it is ordinary text with a thin line through it, and text
  that was already crossed out in the document shows its `~~`.
- Every change card has an amber edge, the colour of its pin and leader line.
  Replaced and Deleted cards title themselves in orange. A removed heading is
  bold, and a removed list item, task or quote keeps its `-`, `- [ ]` or `>`.
- The left-margin bar appears only for changes the text does not show: a
  deletion, a move, a checkbox or math change, and an edit inside a code
  block, where the bar now runs the full height of the block. Green and blue
  text no longer gets a bar beside it.
- Switching from Formatted to Source with changes shown draws the changes at
  once and places the page once, instead of jumping a moment later.
- Fixed: in the app, a mode switch with the middle of the screen above a
  heading or on hidden formatting could jump by half a screen.
- Fixed: a space between two removed words in a card was painted as an orange
  block instead of being crossed out with them.
- Security updates to the HTTP client used for crash reports, and to Phoenix
  LiveView.
