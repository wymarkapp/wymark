The AI sidecar file is retired. Wymark now ships a `wymark` command and an MCP
server that answer a tool's questions about a document's review when it asks,
and a section rewritten in place no longer folds into one change with the
reworded item above it.

## Highlights

- New: the `wymark` command. Turn on **The wymark CLI** in Settings > Review &
  comments and click **Install the CLI**. It asks the running Wymark for a
  document's review (the pending changes, where each came from, and your
  comment threads), lists documents, and moves or copies them with their
  version history.
- New: `wymark mcp` serves the same commands to MCP clients. Settings gives
  each client its route to copy, and Help > **Connect an Agent...** opens it.
- Removed: the AI sidecar file, its toolbar button, its read-only tab and the
  per-document switch. A leftover pointer line in a document is still cleaned
  up. The review format stays `wymark.review/3`.
- Changed: connecting an agent is two steps (turn on and install the CLI,
  then connect the agent once), in Settings and on the last slide of the tour.
- Fixed: after an agent rewrites a section in place, its new blocks are no
  longer folded into the change for one reworded list item above them. One
  Accept for an item edit no longer takes a whole new section with it.
- Fixed: a space beside a comment marker counts as padding only when there is
  a space on its other side.
- Fixed: the text width chosen in zoom survives leaving zoom and coming back.
- Fixed: a Mermaid diagram scrolled out of view stays drawn, so the text below
  it holds still.
- Fixed: choosing an agent in Settings no longer resizes the page.
