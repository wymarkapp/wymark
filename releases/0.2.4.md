Tabs with the same file name stay readable, a branch switch in a linked git
worktree shows up in the Files panel, and a stash with its pop no longer leaves
conflict cards behind.

## Highlights

- Fixed: two tabs with the same file name, such as one file open from a
  repository and from its worktree, now keep the folder that tells them apart.
  Folders both paths share collapse into an ellipsis, and the end of the
  folder name stays beside the file name.
- Fixed: switching branches inside a linked git worktree now updates the
  branch shown in the Files panel, without reopening the folder.
- Fixed: a long branch name no longer pushes the rows of the reference menu
  outside it.
- Fixed: an open document that is stashed and popped (as `git town sync`
  does) no longer keeps the conflict cards the stash raised, and a second
  stash no longer raises them again.
