Switching to the Source view and back keeps your place, and diagrams no
longer push the text around while they draw. Word and PDF export draw Mermaid
diagrams as pictures, a CRLF file stays CRLF, and a document that crashes its
window no longer locks you out of the app.

## Highlights

- New: Word and PDF export draw Mermaid diagrams as pictures. A diagram that
  cannot be drawn, and mindmap and journey diagrams, stay code blocks.
- New: a document that crashes its window twice is closed the next time the
  window opens, with a notice that names it and offers a crash report.
- Improved: going from Formatted to Source and back returns to the same place,
  with the diagrams already drawn. The caret, the outline and tall table rows
  keep their place across a switch too.
- Improved: a reopened document reserves each diagram's space until it draws,
  so the text no longer jumps as diagrams appear.
- Fixed: a file with Windows (CRLF) line endings keeps them through every edit.
  An edit in the Source view used to rewrite the whole file to LF.
- Fixed: in a Word export with track changes, an edit inside a code block no
  longer prints revision markers in the code. The block exports as it stands.
- Fixed: zooming in or out, also in a split, no longer drops the next
  keystroke.
- Fixed: dragging the divider between panes keeps your place after a visit to
  the Source view.
- Fixed: removing front matter from outside while the Source view was open
  could write an empty front matter block back to the file.
- Fixed: a numbered list in a comment card no longer has its numbers cut off.
- Fixed: on Windows, drawings open again, and the link card says Alt-click.
- Fixed: the "cannot install the update" dialog links the download page for
  your system, not always the Mac's.
- Updated: the drawing editor follows excalidraw.com's newest build.
- Security: an update to the database connection library.
